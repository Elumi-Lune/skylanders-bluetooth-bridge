# Security Policy

Le bridge est un prototype communautaire. Il n'expose pas de service réseau, mais dépend du serveur local de VirtPort. Ne rends pas le port 5678 accessible sur Internet.

Les fichiers `.sky`, les dumps NFC et les journaux BLE peuvent contenir des données individuelles. Ne les poste pas publiquement dans les Issues et Pull Requests.

N'installe pas de pilotes tiers depuis des miroirs non officiels. ViGEmBus est archivé et ne reçoit plus de maintenance.

Pour signaler une vulnérabilité, évite de publier une reproduction avec des données personnelles ou des secrets ; contacte les mainteneurs via les moyens privés indiqués sur le futur dépôt GitHub.
